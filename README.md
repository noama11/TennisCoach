
# Personal Tennis Coach Portfolio

This is a personal portfolio website for a tennis coach, built with **React.js** and **Vite**. The site provides an interactive platform where potential clients can learn more about the coach, view engaging 3D visuals, and easily leave their contact details, which are sent directly to the coach's email.

## 🚀 Key Features

- **Interactive 3D Image Display:** Utilizes the Canvas API and other tools to create an engaging visual experience for users.
  
- **Contact Form:** A simple and effective way for potential clients to leave their details, which are then forwarded to the coach via email.

- **Vite-Powered:** The project is built with Vite for fast development and optimized performance, featuring Hot Module Replacement (HMR) and minimal configuration.

- **Clean and Minimal Setup:** Includes basic ESLint rules to maintain code quality and consistency throughout the development process.

## 🗂 Project Structure

- **assets/** - Contains static assets like images and icons.
- **components/** - Modular React components that form the website's UI.
- **hoc/** - Higher-Order Components for shared functionality across the site.
- **utils/** - Utility functions that support various aspects of the website.

## 🛠️ Technologies Used

- **React.js** - A powerful library for building user interfaces.
- **Vite** - A fast and modern build tool that ensures quick development cycles.
- **Canvas API** - Used for rendering 3D images, making the website visually appealing.
- **JavaScript (ES6+)** - Modern JavaScript syntax for improved code clarity and performance.
